# AI Agent Guidelines

Before writing any code in this project, you **must** read and understand the following files:

| File                  | Purpose                                                     |
| :-------------------- | :---------------------------------------------------------- |
| `README.md`           | Project overview, status, architecture, and tech stack      |
| `ROADMAP.md`          | Development phases, pending features, and priorities        |
| `api/README.md`       | Backend architecture, modules, endpoints, and configuration |
| `api/CODESTYLE.md`    | Backend code conventions and patterns                       |
| `client/README.md`    | Frontend architecture, components, routing, and patterns    |
| `client/CODESTYLE.md` | Frontend code conventions and patterns                      |

---

## Code Rules

- **Format code before saving.** Every file must be properly formatted and indented.
- **No comments** unless they are technical and strictly necessary. Self-documenting code is preferred.
- **All code must be written in English.** Variable names, function names, class names, commits, and documentation.
- **Write clean, maintainable code.** Prioritize readability and simplicity over cleverness.
- **Follow the existing patterns.** Match the conventions already established in the codebase — do not introduce new patterns without justification.
